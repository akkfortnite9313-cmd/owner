# ClassBot — сам заходит на пары в Google Meet и Zoom

Программа для Windows. Вы один раз вписываете расписание и нажимаете «Запустить». Дальше бот сам:

- **перед парой** следит за лентой курса в Google Classroom и берёт ссылку на **Meet или Zoom**, которую выложил преподаватель (или использует постоянную ссылку, если она не меняется);
- **заходит в звонок** с выключенными камерой и микрофоном (браузер бота вообще не получает к ним доступа) и без звука на колонках;
- **сидит до конца пары** и выходит; если выкинуло — заходит снова;
- **пишет в Telegram**: зашёл, вышел, не смог зайти (со скриншотом), и главное — **если в чате или субтитрах прозвучала ваша фамилия** или «перекличка». Тогда можно быстро зайти с телефона и ответить самому.

> ⚠️ Честно о том, чего бот не умеет:
> - Бот не отвечает за вас. Если преподаватель спросит лично или попросит включить камеру, отвечать придётся вам (для этого и нужны уведомления).
> - Компьютер должен быть включён. Уснуть Windows бот не даст, но у ноутбука при закрытой крышке нужно выставить «Действие при закрытии крышки: ничего не делать».
> - Интерфейсы Meet и Zoom иногда меняются. Обязательно сделайте тестовый заход и проверьте, что всё работает.
> - За то, как к этому отнесётся ваш вуз, отвечаете вы.

## Установка

1. Установите **Google Chrome** — https://www.google.com/chrome/ (если его нет, бот возьмёт Microsoft Edge, но с Chrome надёжнее).
2. Скачайте **ClassBot.exe**: на странице репозитория на GitHub откройте вкладку **Actions** → последний зелёный запуск «Тесты и сборка ClassBot.exe» → внизу в разделе **Artifacts** нажмите **ClassBot-windows**. Скачается zip, внутри `ClassBot.exe`.
3. Положите `ClassBot.exe` куда удобно (например, на рабочий стол) и запустите.
   Windows может показать «Система Windows защитила ваш компьютер»: это потому, что у программы нет платной цифровой подписи. Нажмите **Подробнее → Выполнить в любом случае**.

Python ставить не нужно, всё уже внутри exe.

## Настройка (в окне программы)

1. **Расписание** → «Добавить пару»: название, дни, время и где брать ссылку:
   - **из ленты курса в Classroom**: откройте курс в браузере и скопируйте адрес из адресной строки (`https://classroom.google.com/c/…`);
   - или **постоянная ссылка** на Meet/Zoom, если она всегда одна и та же. Для Zoom можно указать код доступа, если его нет в ссылке.
2. **Уведомления**: создайте бота в Telegram через @BotFather (`/newbot`), вставьте токен, нажмите «Подключить» и напишите своему боту любое сообщение. Впишите **свою фамилию** в список слов.
3. **Настройки**: впишите имя для Zoom. Остальное можно не трогать. Галочка «Запускать вместе с Windows» включает автозапуск, и бот сам начнёт работать после включения компьютера.
4. **Главная** → «Войти в аккаунты». Откроется отдельное окно браузера (ваш обычный браузер не затронут). Войдите в Google-аккаунт для Classroom, а в Zoom — если преподаватели требуют вход. Закройте окно.
5. **Главная** → «Проверить всё»: бот проверит Telegram, вход в Google и покажет, какие ссылки видит в лентах курсов.
6. **Главная** → «Тестовый заход…»: создайте свою встречу в Meet или Zoom (лучше с другого аккаунта или попросите друга) и вставьте ссылку. Бот зайдёт на 3 минуты. Проверьте, что камера и микрофон выключены, а через полминуты напишите в чат встречи свою фамилию — придёт уведомление.
7. **«Запустить»**. Пока бот работает, окно можно свернуть, но не закрывать.

Чтобы бот слышал фамилию, сказанную вслух, в Meet: во время тестового захода выберите в окне бота язык субтитров «русский» (**⋮ → Settings → Captions**).

## Zoom

По умолчанию бот заходит в Zoom **через браузер** (веб-версия Zoom): видит, что зашёл, и следит за чатом. Если бот не вошёл в аккаунт Zoom, он представится именем из настроек.

Если Zoom в браузере не пускает (просит пройти «я не робот» или у преподавателя запрещён вход из браузера), попробуйте так:
1. Войдите в Zoom в окне бота (кнопка «Войти в аккаунты», вкладка Zoom). Обычно после этого проверок нет.
2. Или в **Настройках** выберите «Zoom в приложении». Тогда бот открывает встречу в установленном приложении Zoom и закрывает его в конце пары. Чат в этом режиме бот не видит. В самом приложении Zoom один раз включите в настройках «Выключать микрофон при входе» и «Выключать видео при входе».

## Как бот находит ссылку в ленте

1. За час до пары бот запоминает, какие ссылки на звонки (Meet и Zoom) уже есть в ленте курса.
2. За 15 минут до начала начинает проверять ленту каждые 30 секунд. Ссылку, которой раньше не было (или которую выложили повторно), считает ссылкой на эту пару.
3. Заходит в звонок за 1 минуту до начала.
4. Если через 3 минуты после начала новой ссылки нет, заходит по самой свежей из имеющихся. Ленту он проверяет и дальше: появится новая ссылка — перейдёт на неё.

Все эти минуты меняются во вкладке «Настройки».

## Если что-то не работает

- **«Бот не вошёл в аккаунт»** — «Войти в аккаунты» ещё раз (сначала остановите бота).
- **Google пишет «Этот браузер может быть небезопасным»** — установите Google Chrome и войдите снова. Если не помогло, после проверки согласитесь войти «прямо в окне бота».
- **Бот не смог зайти / не нажал кнопку** — в Telegram приходит скриншот. Кнопка «Папка с журналом» открывает журнал `bot.log`, скриншоты (`.png`) и сохранённые страницы (`.html`). Скорее всего, поменялся интерфейс Meet или Zoom. Надписи кнопок собраны в начале файлов `classbot/meet.py` и `classbot/zoom.py`.
- **Антивирус ругается на ClassBot.exe** — так бывает с программами, собранными PyInstaller. Можно собрать самому из исходников (ниже) или запускать без exe.

Настройки, профиль браузера бота и журнал лежат в `%LOCALAPPDATA%\ClassBot`. Никому не передавайте папку `chrome-profile`: в ней ваш вход в Google.

## Для разработчика

Запуск из исходников: установите Python 3.10+, запустите `1_install.bat`, потом `ClassBot.bat` (или `python main.py`).

```
python main.py                       # окно
python main.py run | login | telegram | check | join <ссылка> -m 3   # без окна
python -m pytest                     # тесты (для браузерных: python -m playwright install chromium; для окна — экран или xvfb-run)
pyinstaller ClassBot.spec            # сборка dist/ClassBot.exe
```

GitHub Actions (`.github/workflows/build.yml`) на каждый push гоняет тесты, собирает `ClassBot.exe` на Windows и проверяет его командой `ClassBot.exe selftest`. Для тега `v*` exe выкладывается в Releases.

| Файл | Что делает |
|---|---|
| `classbot/gui.py` | окно программы |
| `classbot/runner.py` | главный цикл: расписание → ссылка → звонок → выход |
| `classbot/meet.py`, `classbot/zoom.py` | работа со страницами Meet и Zoom |
| `classbot/classroom.py`, `classbot/links.py` | лента курса и поиск новой ссылки |
| `classbot/mentions.py` | поиск фамилии в чате и субтитрах |
| `classbot/config.py` | расписание и настройки (`config.yaml`) |
| `classbot/tasks.py` | проверка, вход, тестовый заход |
| `classbot/notify.py` | Telegram |
